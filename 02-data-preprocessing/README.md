# Data Preprocessing

Tahap preprocessing pada notebook mencakup penghapusan identitas transaksi/deskripsi yang kosong, invoice pembatalan, quantity tidak valid atau tidak positif, kode non-produk, pemilihan transaksi United Kingdom, penghapusan produk ganda per invoice, dan penyaringan transaksi yang memiliki kurang dari dua produk unik.

Rincian jumlah baris dan invoice pada tiap tahap dicatat dalam tabel ringkasan preprocessing di notebook.
