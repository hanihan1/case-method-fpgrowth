# Implementasi FP-Growth

Notebook Google Colab untuk membentuk transaksi biner, menjalankan FP-Growth, membangkitkan association rules, serta membuat rekomendasi berbasis hasil analisis.

Buka `FP_Growth_Online_Retail_Colab_revisi.ipynb` dan unggah dataset `Online_Retail.xlsx` ketika diminta. Parameter utama (`MIN_SUPPORT`, `MIN_CONFIDENCE`, `MIN_LIFT`, dan `MAX_LEN`) dapat disesuaikan.
