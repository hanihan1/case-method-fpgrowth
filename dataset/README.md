# Dataset

Folder ini berisi data dan dokumentasi terkait dataset yang digunakan pada Case Method FP-Growth.

## Isi yang direkomendasikan
- File dataset mentah, misalnya `Online_Retail.xlsx`
- Keterangan sumber dan karakteristik data
- Ringkasan kualitas data
- Nilai hilang, transaksi pembatalan, dan ringkasan distribusi

## Penjelasan data
Dataset Online Retail berisi transaksi ritel yang digunakan untuk menganalisis pola keranjang belanja. Dalam analisis ini, setiap invoice diperlakukan sebagai satu transaksi.
