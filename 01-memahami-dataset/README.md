# Memahami Dataset

Tahap ini mengenali struktur dataset Online Retail, unit observasi, periode transaksi, negara, tipe data, nilai hilang, transaksi pembatalan, serta distribusi awal. Dalam analisis ini, setiap `InvoiceNo` diperlakukan sebagai satu keranjang belanja.

Eksplorasi dan ringkasan dataset tersedia pada bagian Langkah 1 notebook implementasi.
